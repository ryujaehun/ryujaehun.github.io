Hello, I'm Jaehun Ryu, a compiler engineer at [Rebellions](https://rebellions.ai/).

This blog organizes what I study about compiler technology and optimization for running AI models efficiently on hardware. It focuses on paper reviews and open-source code reading, alongside C++, development experiences, and occasional personal notes.

## Where to start

- [LLM inference optimization](/en/categories/llm-inference/): paper reviews on speculative decoding, cache compression, serving, and scheduling.
- [KV caches](/en/tags/kv-cache/): compression, quantization, eviction, offloading, and prefix reuse.
- [Inference engine code reading](/en/categories/code-series/): series following execution paths through open-source projects.
- [Abseil and C++](/en/categories/abseil/): notes on C++ programming and API usage.

## Reading these notes

These are personal study notes and may contain errors or differences in interpretation. Read reported results in the context of the paper's models, hardware, and evaluation settings. When considering a practical application, consult the linked original papers and project code as well.
