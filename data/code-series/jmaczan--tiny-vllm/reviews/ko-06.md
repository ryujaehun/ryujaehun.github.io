# ko-06 리뷰 — 블록 단위로 인덱싱되는 paged KV cache

고정 revision `e25bf1994efa90bc98b721ba7c527402f86fbeaf` 의 체크아웃 트리
(`src/main.cpp`, `src/kernels.cu`, `src/kernels.cuh`)와 첨부 증거(`guide.md`,
`series.yaml`, `evidence/claims.md`, `evidence/trace.md`, `evidence/recon.md`)를

## Decision

**PASS**

KV cache 할당자 세 조각, 블록 레이아웃(`BLOCK_SIZE`/`V_OFFSET`/`BLOCK_BYTES`/
`NUM_BLOCKS`), prefill·decode 두 분산 지점의 3항 인덱싱, `pagedAttentionKernel`
의 그리드 매핑·block table 순회·K/V 주소 산술, 네 상태 입력의 비대칭, 워프 셔플
리덕션과 온라인 소프트맥스, in-place 출력, 할당·반납·H2D 동기화까지 모든 기술
주장이 실제 소스와 첨부 증거에 정확히 일치한다. `block-table-indexing`(mermaid)
과 `paged-attention-inputs`(표) 두 시각 자료가 `series.yaml` 의 필수 주장을
답하고, 최소 근거 `code 5 / tests 0 / runtime 0` 을 충족하며, 측정값으로 읽힐
성능 수치도 없다. 수정을 요구하는 오류는 찾지 못했다. 아래 O1 은 비차단 정밀도
관찰이며 수정 선택 사항이다.
