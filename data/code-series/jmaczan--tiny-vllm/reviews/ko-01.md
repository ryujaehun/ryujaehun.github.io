## Decision

**REVISE**

인용 줄 번호·산술·범위·시각 자료·제약 서술의 대부분은 실제 소스와 일치하며
차단 수준의 오류는 없다. 다만 같은 대상의 소유 편을 두 곳에서 다르게 적은
내부 모순 한 곳(P1)과, 사실이 아닌 줄을 가리키는 인용 한 곳(P2)이 있어 수정을
요구한다. P1 은 초안 스스로가 인용한 소스(`src/kernels.cu`)에서 직접 검산
가능한 귀속 오류다.

## Problems

**P1 (소유 편 귀속 모순).** 5편 소유를 정리한 목록에서 "decode 계열 커널
변형과 `WARP_FULL_MASK` 의 소비: 5편(`guide.md:198`)"
(`articles/ko-01.md:250`)이라고 적었는데, 같은 글의 앞부분에서는 "이 상수의
소비는 decode 계열 `pagedAttentionKernel` 에 있으며 **6편**이 소유한다"
(`articles/ko-01.md:155-156`)라고 적었다. `WARP_FULL_MASK` 는
`pagedAttentionKernel`(`src/kernels.cu:461`) 내부 `489-493` 에서만 소비되고,
paged attention 은 `guide.md:199` 가 6편 소유로 규정한다. 즉 155-156 의 6편이
맞고 250 의 5편이 틀리다. `guide.md:198` 은 "decode 스텝"을 5편으로 두지만
`WARP_FULL_MASK` 소비는 그 범위가 아니다. 초안 내부의 직접 모순이자 소스로
검산 가능한 귀속 오류다.

**P2 (사실과 다른 줄 인용).** "runtime 은 0 이므로(결정 003,
`guide.md:81`)"(`articles/ko-01.md:23`)에서 runtime 0 을 가리키는 줄은
`guide.md:85` 다. `guide.md:81` 은 정적 대체 검증을 택한다는 결정 003 의
서술일 뿐 `required_evidence.runtime` 값이 아니다. 같은 글의 한계 절에서는
`guide.md:85` 를 정확히 인용하고 있어(`articles/ko-01.md:262`) 서로 어긋난다.
