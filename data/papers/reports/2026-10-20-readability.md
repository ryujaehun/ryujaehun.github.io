# 오늘 공개 글의 설명 방식 개선

- 공개된 한국어 원문은 FlashMask-3와 DLite 두 편이다. FlashMask-3의 직전 개정 방식을 DLite 한국어·영어에도 적용했다.
- DLite는 본체 캐시 유지/초안 이력 캐시 제거, 후보 통과/거절/뒷부분 폐기를 새 SVG 예시로 설명한다. 단어는 실제 토큰 분할과 구분한다.
- 본문에서 SWE-Bench 수용 길이와 일반 생성 대비 속도를 분리하고 DSpark 대비 속도 비율은 계산값으로 설명했다.
- arXiv HTML 원문을 대조해 방법 §4.1, 학습 §4.2, 실험 §5.1, Table 1/3/4 근거를 정정했다.
- 원문 표의 모든 행은 유지하고 참고 영역을 접었다. 원문 그림과 직접 그린 설명용 그림의 출처를 구분했다.
- 기본·운영 프롬프트, 우선 품질 계약, 2차 가독성 퇴고에 동일한 입력/상태/변경/출력 설명 기준을 반영했다. 파일을 생성하지 않는 자동 작성은 표·Mermaid를 사용한다.
- 3차 사실 대조는 가독성 구조를 유지한다. 기존 단계별 모델 선택 테스트에 이 지시가 전달되는지 검증을 추가했다.
- 전체 자동화 테스트 969개, 수정 후 퇴고 테스트 53개, Ruff와 양언어 글 검사, 번역 수치·구조 검사, Hugo 빌드 통과.
