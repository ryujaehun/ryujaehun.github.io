# 논문 리뷰 영어 번역 단계

- 날짜: 2026-09-07
- 상태: 구현 완료 (`blog-automation` `c9d9b43`, 블로그 `be0dbcd`)
- 범위: 서브프로젝트 3. 사용법은 `automation/README.md` 의 "영어 번역".
  이 문서는 **왜 그렇게 했는지**만 남긴다.

## 번역이지 재요약이 아니다

두 갈래가 있었다.

| | 방식 | 비용 | 두 글의 관계 |
|---|---|---|---|
| **채택** | 한국어 본문 → 영어 번역 | 입력이 짧아 싸다 | 정확히 대응 |
| 기각 | PDF → 영어로 재요약 | 요약을 두 번 = 두 배 | 미묘하게 갈라진다 |

재요약은 영어가 더 자연스러울 수 있지만, 같은 논문의 두 페이지가 서로 다른
내용을 말하게 된다. 독자가 언어를 바꿨을 때 다른 글이 나오는 건 버그다.

## 진짜 문제는 번역이 아니라 구조 보존이다

본문에는 mermaid 다이어그램, LaTeX 수식, 마크다운 표가 섞여 있다. 실측한
글 하나에 코드펜스 2개, 표 19행, `$$` 4개가 있었다.

번역 모델이 코드펜스를 하나 빠뜨리면 **그 뒤 문서 전체가 코드 블록으로
렌더링된다.** 페이지가 통째로 깨지고, 무인 실행이라 아무도 모른다.

그래서 옮긴 결과를 세어 본다.

| 검사 | 기준 | 왜 |
|---|---|---|
| 코드펜스 개수 | 정확히 일치 | 하나만 어긋나도 뒤가 다 깨진다 |
| `$$` 개수 | 정확히 일치 | 수식이 본문으로 흘러나온다 |
| 표 행 개수 | 원문의 80% 이상 | 정렬 구분선이 붙거나 빠질 수 있어 여유를 둔다. 표가 통째로 사라지는 것만 잡는다 |
| 길이 | 원문의 50% 이상 | 번역이 아니라 요약을 해 온 경우 |
| 남은 한글 | 2% 미만 | 번역이 덜 됐다. 고유명사로 한두 자 남는 건 통과 |

어긋나면 **`.en.md` 를 쓰지 않는다.** 깨진 영어 페이지를 올리는 것보다 없는
게 낫다. 한국어 글은 이미 게시된 상태로 남는다.

workflow 의 이 단계는 `continue-on-error: true` 다. 번역 실패가 한국어
게시를 되돌리게 하면 안 된다.

## 머리말은 번역하지 않고 물려받는다

파이프라인이 만든 글은 `title` 이 이미 영어(arXiv 원제)라 옮길 게 없다.
`categories`·`tags`·`date` 는 두 언어가 **같아야** Hugo 가 짝으로 묶는다.
그래서 한국어 글의 머리말을 그대로 쓰고 `draft` 만 갈아 끼운다.

기존 영어 글 17편에는 `draft` 필드가 아예 없다. 백필할 때 걸리므로
없으면 추가한다.

## 대상은 기본적으로 오늘 글만

기존 논문 글 419편 중 **407편이 영어가 없다.** 기본 대상을 "`.en.md` 가
없는 모든 글" 로 두면 한 번의 실수로 407편이 돌아간다.

그래서 기본은 오늘 날짜 글만이고, 과거 글은 `--backfill --limit N` 을
명시해야 건드린다. 사용자 선택: **cron 은 새 글만, 백필은 수동.** 번역
품질을 몇 편 보고 판단한 다음 양을 정하기로 했다.

## 모델

| | 모델 | 근거 |
|---|---|---|
| 요약 | `opencode-go/deepseek-v4-pro` | 논문 PDF 를 읽고 해석해야 한다 |
| 번역 | `opencode-go/deepseek-v4-flash` | 번역은 더 쉬운 일이다 |
| 폴백 | `opencode/muse-spark-1.3-contributor-free` | 프로바이더 한도·장애 대비 |

실측 비용(2609.01343): 요약 $0.0083, 번역 $0.0163. 번역이 더 비쌌는데,
입력이 짧은 대신 출력이 원문 길이만큼 나오기 때문이다. 하루 2편이면
합계 $0.05 남짓이다.

## 구현 중 고친 것

`build_opencode_command` 가 `pdf_path` 를 필수로 다루고 있었다
(`Path(pdf_path).absolute()`). 번역은 첨부할 파일이 없어 `--file` 을
조건부로 바꿨다.

## 검증

실측(2609.01343, `deepseek-v4-flash`, 2분 37초):

- 200행 원문 → 200행. 코드펜스 2, 표 19행, `$$` 4 가 정확히 보존.
- 한글 0자. `[논문 링크]` → `[Paper]`, `(근거: §1)` → `(source: §1)`.
- `hugo --gc --minify`: KO 998→1004, EN 191→196 페이지.
- 영어 페이지에서 mermaid 1블록·KaTeX·표 3개 렌더링 확인.
- `hreflang` 이 ko↔en 짝을 서로 가리키는 것 확인.

## 남은 것

- 기존 407편 백필 (수동, 양은 품질을 보고 결정)
- 확인된 `<h1>` 중복이 영어 글에도 그대로 있다. 테마가 머리말 `title` 로
  h1 을 만드는데 본문도 `# 제목` 으로 시작한다 — 서브프로젝트 5 소관이다.
