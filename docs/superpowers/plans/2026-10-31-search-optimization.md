# 검색 최적화 구현 계획

목표: 기존 Hugo 구조를 유지하며 Google·Bing·네이버가 같은 페이지 주소와 색인 신호를 읽게 한다. 새 플러그인이나 외부 추적 서비스는 추가하지 않는다.

- [x] 렌더 결과 검사기를 먼저 만들고 canonical·OG 이미지 오류를 재현한다.
- [x] 페이지네이션 URL을 canonical·OG·CollectionPage에 함께 적용한다. 번역 목록의 글 수와 페이지 경계가 다르므로 2쪽 이후에는 hreflang을 생략한다.
- [x] robots 결정을 공통 partial로 모으고 noindex/none 페이지를 사이트맵과 RSS에서 제외한다.
- [x] 기본 공유 이미지를 실존 파일로 수정하고 RSS에 최신 글 30편의 본문 전체를 제공한다.
- [x] 한국어·영어 사이트 설명을 실제 기술 주제에 맞추고 새 글에 description 필드를 마련한다.
- [x] 전체 빌드와 검색 메타·내부 링크 검사를 수행하고 배포 CI에 검색 메타 검사를 연결한다.
- [x] 네이버 계정에서 필요한 사이트맵·RSS 제출 절차와 콘텐츠 운영 권고를 기록한다.

검증은 Python 표준 라이브러리만 사용한다. 기존 소유 확인 파일은 보존한다. 배포·계정 설정 변경은 이번 로컬 변경에 포함하지 않는다.
